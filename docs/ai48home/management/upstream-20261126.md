# Upstream integration review: 2026-11-26

This maintenance branch integrates upstream Home `9208558..dcc3900` into fork
`fa17a89`. It is not approved for deployment.

## Conflict decisions

- Keep organization, playground, top-up and durable quota-guard migrations and
  snapshot mappings. Fork version 30 and upstream version 21 combine at **31**.
  The new startup data migration namespaces existing OpenAI-compatible provider
  keys. Version 30 snapshot layout remains supported unchanged; no occupied

## API changes requiring coordinated review

Upstream adds the `antigravity_tos_pause_status` capability and read-only
`GET /v8/management/routing/antigravity/tos-pause`, Copilot OAuth/catalog support,
credential-scoped Antigravity model enums, expanded billing import discovery and
namespaced OpenAI-compatible provider keys. Detailed upstream API changes remain
in `docs/management/api.md` and `api_CN.md`. The fork's English/Chinese full API
references still need coordinated updates before this draft is ready.

The Vue UI is not replaced with the React upstream. The Rust worker is not
replaced with Go. Provider namespace and new payload/config compatibility with
the Rust worker require explicit acceptance; a Home compile does not establish
cross-project compatibility. Do not enable unsupported Copilot/Devin executors.

## Verification and limitations

`go build -o /dev/shm/ai48home-maintenance-20261126 ./cmd/home` passed; the normal
on-disk output initially failed because the filesystem ran out of space.
Registry, auth, Home and dynamic RESP dispatch package tests passed. Isolated
SQLite tests for fresh/legacy migration, snapshot compatibility, provider-key
migration (including repeat application), and combined-version mapping passed.
PostgreSQL migration integration was not run; no production database was used.

The user API suite failed four existing contract assertions around analytics,
date-range validation and unattributed request-log visibility. A baseline
comparison was attempted; its actual result must be checked in the external log
before classifying these as pre-existing. Full cluster/management test outcomes
are recorded in the maintenance PR. Disk pressure also interrupted initial test
linking. Do not treat this branch as verified or ready until all blockers are
resolved. No deployment, restart or production migration was performed.
